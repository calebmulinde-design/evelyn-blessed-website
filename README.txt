# Artist Website

## How to open it

1. Extract this folder.
2. Open the folder in VS Code.
3. Open `index.html`.
4. Either double-click `index.html`, or use VS Code's **Live Server** extension and click **Go Live**.

## Where the photos are

All five supplied photos are already connected inside:

`images/`

The website currently uses:
- `hero.jpg` — home/hero section
- `portrait.jpg` — about section
- `gallery-1.jpg`, `gallery-2.jpg`, `gallery-3.jpg` — gallery/music/contact

## What you should replace

Search `index.html` for:
- `Artist Name`
- `New Song Title`
- `bookings@example.com`
- `+256 700 000 000`
- sample event dates
- sample social links

Replace those with the singer's real information.

## Main files

- `index.html` — website content
- `style.css` — design and responsive layout
- `script.js` — menu, animations and gallery lightbox
- `images/` — supplied photos

No framework or build process is required.
